The pages in this section introduces some of the key concepts in Materialize:

Component                                | Use
-----------------------------------------|-----
[Clusters](/self-managed/v2025.01/concepts/clusters/)          | Clusters are isolated pools of compute resources for sources, sinks, indexes, materialized views, and ad-hoc queries.
[Sources](/self-managed/v2025.01/concepts/sources/)            | Sources describe an external system you want Materialize to read data from.
[Views](/self-managed/v2025.01/concepts/views/)    | Views represent a named query that you want to save for repeated execution. You can use **indexed views** and **materialized views** to incrementally maintain the results of views.
[Indexes](/self-managed/v2025.01/concepts/indexes/)            | Indexes represent query results stored in memory.
[Sinks](/self-managed/v2025.01/concepts/sinks/)                | Sinks describe an external system you want Materialize to write data to.

Refer to the individual pages for more information.
